# אַרְגַּז הַמִּשְׂחָקִים שֶׁל קָאִי

אתר משחקים ופעילויות לבית, בעברית מנוקדת, לילדה בת 7.

**חי כאן:** https://shirashay.github.io/kai-games/

## מה יש בו

- **מְכוֹנַת הָרַעְיוֹנוֹת** — כפתור שמגריל משחק, עם שלוש-ארבע הוראות מוכנות להתחלה מיידית.
- **37 משחקים** בקטגוריות: רִקּוּד, שִׁירָה, קְרִיאָה, יְצִירָה, מַדָּע, סִפּוּרִים, הַצָּגוֹת, דִּמְיוֹן,
  חֲשִׁיבָה, תְּנוּעָה, בְּנִיָּה. לכל משחק: זמן, גיל, מד בלאגן, חומרים, הוראות, ושדרוג.
- **סינון** לפי סוג, זמן, וכמה בלאגן זה עושה.
- **10 שְׁאֵלוֹת עַל הָעוֹלָם** — תשובה אמיתית בשפה פשוטה, ובסוף כל אחת ניסוי קטן לבית.
- **הַקְרָאָה בְּקוֹל** — כפתור רמקול על כל כרטיס, ומצב הקראה כללי שבו נגיעה בכל דבר בדף מקריאה אותו.
- **הַמְצָאָה חֲדָשָׁה** — מחולל שמרכיב משחק שלא היה קיים (כ-145,000 שילובים), עם שדה שבו קאי
  נותנת לו שם משלה.
- **מעקב אישי** — "שִׂחַקְתִּי אֶת זֶה" נשמר ב-`localStorage` של המכשיר, עם מד התקדמות.

## איך זה בנוי

קובץ אחד, `index.html`. בלי בילד, בלי תלויות, בלי רשת בזמן ריצה. כל התוכן (משחקים ושאלות) יושב
כמערכי JavaScript בתוך הקובץ: `GAMES`, `QUESTIONS`, ומערכי המחולל (`THINGS`, `ACTIONS`, `PLACES`,
`CHALLENGES`, `SCORES`, `TITLES`).

- **הקראה:** Web Speech API (`speechSynthesis`) עם `lang="he-IL"`. באייפד/מק הקול הוא Carmit.
  אימוג'י מסוננים לפני ההקראה, והטקסט נחתך למשפטים כדי שאפשר יהיה לעצור באמצע.
- **מחולל ההמצאות:** תבניות עם placeholders (`{them}`, `{from}`, `{to}`, `{on}`) שמתמלאים לפי מין
  החפץ (`f: true` = נקבה רבים), כדי שלא ייצא "כּוֹסוֹת... אוֹתָם".
- **ערכות נושא:** בהיר וכהה דרך CSS custom properties, גם `prefers-color-scheme` וגם
  `data-theme` על שורש המסמך.

## איך מעדכנים

עורכים `index.html`, ואז:

```bash
git add index.html && git commit -m "..." && git push
```

GitHub Pages מתעדכן תוך כדקה. אם הדפדפן מציג גרסה ישנה — לרענן עם `?v=2` בסוף הכתובת.

## להוסיף משחק

מוסיפים אובייקט למערך `GAMES`:

```js
{
  t: "שֵׁם הַמִּשְׂחָק", e: "🎈", cat: "יְצִירָה", time: 20, mess: 1, age: "5+",
  tint: "var(--mint)",
  line: "מִשְׁפָּט אֶחָד שֶׁמַּסְבִּיר מָה עוֹשִׂים.",
  stuff: "מָה צָרִיךְ",
  steps: ["הוֹרָאָה רִאשׁוֹנָה.", "שְׁנִיָּה.", "שְׁלִישִׁית."],
  twist: "אֶפְשָׁרוּת לְשַׂחֵק שׁוּב אַחֶרֶת."
}
```

הכללים לתוכן חדש (ניקוד, אורך משפט, מין דקדוקי, ערכי `cat` ו-`tint` החוקיים) מתועדים ב-`CLAUDE.md`.
